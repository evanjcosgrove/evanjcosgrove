### Mindara

I co-founded [Mindara](https://mindara.io) with [Justin Casso](https://github.com/jrcasso), and we build it together. We already had more saved places than we could get through; turning them into plans with friends was the part that needed work.

Mindara connects recommendations, live restaurant availability through Resy, and booking with the user's approval, using agentic workflows built on Gemini running on Vertex AI. [More info](https://github.com/evanjcosgrove/fde-case-studies/blob/main/mindara.md).
